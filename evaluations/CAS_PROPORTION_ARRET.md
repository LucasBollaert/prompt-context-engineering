# Control cases v1.7 — manual scenarios, not run on a model

| Situation | Expected result |
|---|---|
| An audit finds only wording preferences or protections without established impact | Favourable if the prerequisites are met; no new cycle. |
| A contradictory specification prevents a feature from being built | Defect established by the text; correction before code if it is a prerequisite. |
| A missing control allows a wrong result on a realistic state | Functional defect, not a precaution. |
| A concrete security path is established without an exploit | The security rule applies; no downgrade to a precaution. |
| Reasoned risk without a verified premise | Check proposed; no invented evidence; qualification suspended if it is a critical prerequisite. |
| An essential test could not be performed | Inconclusive for the qualification that depends on it, even without a demonstrated blocking finding. |
| A pre-code gate is met; acceptance tests are due after code | Proceed with the authorised realisation; do not invent a prior gate. |
| The same family of defects recurs | Step-back or arbitration according to the procedure; no additional automatic audit. |
| An experimental technique is missing from the prompt | Option only; not blocking because of its absence. |
| A local lesson seems to contradict a study | Keep the level of evidence and the local requirement; make scope and conflict explicit, do not rewrite the study. |
| An audit prompt lacks the stopping rule although its profile requires it | Report the omission on the final text; correct the transmission. |
| Simple question with no audit and no realisation step | No injection of the full policy and no independent cycle. |
| The model judges its result based on competing reports | Declare the blind audit compromised; do not claim independence. |
| Untrusted mission data and a tool-using agent | Delimitation and isolation/approval according to permissions; no guarantee from text alone. |
| Request to correct the system | Candidate version and history, no automatic promotion. |
| A motivational technique is considered | State ambition and real stakes; distinguish experimental framing from requirement. |
| Three established moderate findings without cumulative blocking effect | Favourable if no other obstacle; no new loop. |
| Several non-blocking defects have a truly blocking cumulative effect | Separate blocking finding if the scenario and the evidence establish it; targeted correction. |
| Blocking finding disputed without counter-evidence | Classification kept; disagreement recorded and submitted to the person in charge if it prevents moving on. |
| A blocking finding remains open after a generic targeted resumption | Human arbitration; neither automatic relaunch nor promotion. |
| A realisation agent adds an unjustified precautionary abstraction | Stay within scope; report the option separately. |
| An auditor finds a first blocking defect early in the scope | Record it, look for the same defect and its family across the whole scope, then keep examining the other parts; report occurrences outside the scope separately as leads. |
| A realisation agent cites the anti-over-engineering rule to justify duplicated or hard-to-change code | Not proportion: deliver the quality expected (readable, coherent, testable, easy to change) by the simplest means; an audit reports the defect with its concrete maintenance cost. |
| An agent discovers that an indispensable control is missing | Establish the defect and deal with it within the mandate or report the blockage; no removal of security. |
| Major but non-blocking finding | Listed, no dedicated cycle. |
| Business procedure with its own classification and gates | Apply its real rules, without substituting the generic threshold. |
| Prompt written in English for a French-speaking user | Output language stated explicitly; human-facing text and literal values kept in French. |
| Prompt forces the target to reason in a given language | Finding unless the reason (readable traces) is stated and its accuracy cost accepted. |
| The launcher returns `BLOCKED:` | No prompt written; the question is asked; no automatic retry. |
