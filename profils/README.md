# Profils métier
Ce dépôt ne contient aucune donnée métier privée. Pour un projet, fournir un profil autorisé à part, basé si utile sur `MODELE_PROFIL.md`. Le profil ne remplace pas les connaissances scientifiques. Ne pas rendre les exigences d'un autre projet universelles. Aucun profil n'est obligatoire pour une demande simple.
